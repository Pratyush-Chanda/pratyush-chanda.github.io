# Pratyush Chanda — Personal Site

A static, GitHub Pages-ready bio page for Pratyush Chanda. The page is intentionally dependency-free: the source is plain HTML, CSS and JavaScript, and the included Node script produces a clean `dist/` static output.

## Local preview

```sh
npm start
```

The preview server listens on port 3000 by default. To verify the production copy:

```sh
npm run build
```

## Content notes

The page uses the public GitHub avatar and profile link for `Pratyush-Chanda`. The LinkedIn row is intentionally marked as a placeholder until the final profile URL is supplied. The copy preserves the AI-assisted/vibe-coded implementation disclosure from the supplied developer bio.
