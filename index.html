02profile

A practical curiosity

The computer is more interesting when it stops being a black box.

Technology enthusiast focused on Linux, operating systems, Android firmware, privacy-oriented computing and AI-assisted software prototyping.

My longest-used Linux daily driver has been Void Linux, which I used for approximately a year. I have also daily-driven Artix Linux and Nobara, experimented with window managers, login managers, GRUB, services, networking and permissions, and built a working intuition for the small decisions that make a system feel like your own.

Curiosity usually starts with a question: what is this layer doing, can it be changed, and what would a more open alternative look like?

04field note

A real experiment

The boot path is never just software.

I investigated custom splash-screen implementation and Android boot/firmware behaviour on an ASUS ZenFone Max Pro M2, then attempted a postmarketOS port using Halium and experimented with Qualcomm EDL recovery.

The effort ended after an eMCP/eMMC hardware failure. That ending was useful too: it made the boundary between a software problem and a physical one impossible to ignore.

05long view

Where this is heading

Toward hardware people can afford, understand and keep.

The long-term interest is not hardware for its own sake. It is a more generous relationship with the hardware underneath our software.

That means development boards and smartphones designed around affordability, developer access, repairability, documentation, alternative operating-system support and long-term maintainability.
